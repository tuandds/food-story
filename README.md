# Food Story

HTML5 merge & order game (portrait 9:16). Tap ingredients on the plates to send them to the looping conveyor; three identical ingredients merge into a dish that is served to the matching customer. Lose when the conveyor is full, win when every customer is served.

## Run

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765 (opening `index.html` directly from disk won't load the images).
